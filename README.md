# NOIR — Modern Men's Grooming

**Brand personality:** Luxury, masculine, sophisticated, editorial.

## Design System

| Token | HEX | RGB |
|---|---|---|
| Primary | `#111111` | `rgb(17, 17, 17)` |
| Secondary | `#2A2A2A` | `rgb(42, 42, 42)` |
| Background | `#F4F1EB` | `rgb(244, 241, 235)` |
| Surface | `#E8E3DA` | `rgb(232, 227, 218)` |
| Text | `#171717` | `rgb(23, 23, 23)` |
| Muted Text | `#6B6862` | `rgb(107, 104, 98)` |
| Accent | `#B08D57` | `rgb(176, 141, 87)` |
| Accent Light | `#D2B98A` | `rgb(210, 185, 138)` |

## Usage Rules

- Use black and warm off-white as the foundation.
- Gold should be used sparingly for buttons, borders, icons and highlights.
- **60%** Background/neutral · **30%** Primary/Secondary · **10%** Accent.
